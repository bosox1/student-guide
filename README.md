# Student Guide — ІФНМУ (React)

Переписана версія сторінки Student Guide на React + Vite, з тим самим функціоналом:
навігація по локаціях, модалка з реквізитами оплати (кнопка «Оголошення»), бургер-меню
на мобільних, галереї корпусів/їдалень, список гуртожитків, студентські організації,
контакти й футер.

## Структура

```
student-guide/
├── index.html
├── package.json
├── vite.config.js
├── netlify.toml
├── public/
│   └── img/        ← сюди кладете свої зображення (див. нижче)
└── src/
    ├── main.jsx
    ├── App.jsx      ← вся розмітка/секції
    ├── App.css      ← стилі й дизайн-токени
    └── data.js       ← весь контент (адреси, лінки, підписи) окремо від розмітки
```

## Зображення

Усі фото лежать у `public/img/`. Ще бракує реальних файлів (поки або сірі заглушки,
або файлу немає — тоді картинка просто ховається, без «битої» іконки):

- `stg.jpg` — картинка в модалці «Оголошення» (зараз заглушка 400×300)
- `grants.jpg` — банер партнерів (зараз заглушка 400×300)
- `cafe1.jpg`, `cafe2.jpg`, `cafe3.jpg` — галерея їдалень (файлів немає)

Галерея корпусів — мозаїка з 5 фото (`corpuse1`–`corpuse5`), порядок у
`corpusesGallery` в `src/data.js` задає позицію: 1 — високе зліва, 2 — широке зверху,
3 — середнє, 4 — високе справа, 5 — широке знизу.

## Локальний запуск

```bash
npm install
npm run dev
```

## Деплой на Netlify (піддомен університету)

1. Заведіть репозиторій на GitHub і запуште туди цю папку.
2. У Netlify: **Add new site → Import an existing project**, підключіть репозиторій.
   Netlify сам підхопить `netlify.toml` (команда збірки `npm run build`, публікація
   з `dist`).
3. Після першого деплою: **Site configuration → Domain management → Add a domain** →
   впишіть ваш піддомен (напр. `guide.ifnmu.edu.ua`).
4. У DNS-панелі університетського домену додайте CNAME-запис, що вказує на
   `<ваш-сайт>.netlify.app` (Netlify покаже точне значення в тому ж розділі).
5. Дочекайтесь видачі SSL-сертифіката (Netlify робить це автоматично через Let's Encrypt).

## Що можна легко доробити далі

- Замінити CNAME-плейсхолдер `Education hub` (`../index.html`) на реальне посилання.
- Якщо контактні зображення (`main_contacts1–6`) — це фактично текстова інформація
  на картинках, варто продублювати її текстом для доступності (зараз вони мають
  порожній `alt`, бо є суто декоративними на оригінальній сторінці).
